2. เทคนิคการทำ Data Cleansing ที่ 1 & 2

Slide 3 / 9

🧹 เทคนิค 1: Text Normalization & Sanitization (3 คะแนน)

  • Unicode Normalization (NFKD): แก้ปัญหาฟอนต์และสระภาษาไทยลอย/ซ้อน
  • Regex Cleaning: ตัด Control Characters (\r, \n, \t) และอักขระแปลกปลอม
  • Dosage/Unit Standardization: ปรับหน่วยความแรงยาให้อยู่ในมาตรฐานเดียวกัน (e.g. 500 MG -> 500 mg, 1.0 G -> 1000 mg)
text = unicodedata.normalize('NFKD', text) text = re.sub(r'[\r\n\t]+', ' ', text) val = re.sub(r'\b(mg|milligram)\b', 'mg', val)

🛡️ เทคนิค 2: Deduplication & Orphan Filtering (3 คะแนน)

  • Key Deduplication: ตรวจจับและตัดแถวซ้ำซ้อนใน TMTID และ Parent-Child Pairs
  • Loop Prevention: ลบความสัมพันธ์ Self-referencing (Parent ID == Child ID)
  • Referential Integrity Check: กรองทิ้งความสัมพันธ์ที่ไม่มีตัวตนจริงในตาราง Concept เพื่อป้องกัน Orphan Records
valid_ids = set(concepts['TMTID']) valid_rel = rel[rel['PARENT_ID'].isin(valid_ids) & rel['CHILD_ID'].isin(valid_ids)]

4. การจัดการฐานข้อมูลเชิงสัมพันธ์และการ Query

Slide 5 / 9

💾 2.1 เหตุผลการเลือก Relational DB (3 คะแนน)

  • Referential Integrity: บังคับ Foreign Keys ป้องกัน Orphan Nodes
  • Strict ACID Compliance: ความถูกต้องสูงสุดในระบบจ่ายยาผู้ป่วย
  • Multi-table JOIN & Indexing: เชื่อมโยง 4 ตารางหลักด้วยความเร็ว < 1ms

🏗️ 2.2 ออกแบบ Schema & Ingestion (3 คะแนน)

ตารางหลัก: tmt_concepts, tmt_relations, atc_mappings, hospital_drug_catalog พร้อม B-Tree Index

🐍 2.3 การ Query ผ่าน Python Code (4 คะแนน)

-- Query สืบค้นสายสัมพันธ์ TPU -> GP -> VTM -> ATC SELECT tpu.tmt_id, tpu.trade_name, gp.fsn AS generic_name, vtm.fsn AS therapeutic_name, atc.atc_code FROM tmt_concepts tpu JOIN tmt_relations r1 ON tpu.tmt_id = r1.child_id JOIN tmt_concepts gp ON r1.parent_id = gp.tmt_id JOIN tmt_relations r2 ON gp.tmt_id = r2.child_id JOIN tmt_concepts vtm ON r2.parent_id = vtm.tmt_id LEFT JOIN atc_mappings atc ON vtm.tmt_id = atc.tmt_id WHERE tpu.concept_type = 'TPU';

🤖 Agentic AI Pipeline Supervisor
